El DOM (Document Object Model) 
es una representación del documento HTML en forma de objetos. Permite que JavaScript acceda, modifique, agregue o elimine elementos de una página web.

createElement:
createElement() es un método del objeto document que permite crear un nuevo elemento HTML de forma dinámica mediante JavaScript. El elemento se crea en memoria y no aparece en la página hasta que se agrega al DOM, por ejemplo con appendChild().

appendChild:
appendChild() es un método de JavaScript que agrega un elemento hijo dentro de otro elemento del HTML. Se utiliza para insertar un elemento en el DOM y hacerlo visible en la página.

innerHTML:
Lee o escribe el código HTML interno de un elemento.
Cuando necesitas insertar o modificar etiquetas HTML.
Cuando se requiere inyectar o modificar etiquetas HTML dinámicamente (<b>, <div>, <a>, etc.).

textContent:
Lee o establece el texto plano de un elemento y de todos sus descendientes, ignorando cualquier etiqueta HTML.
Cuando solo necesitas mostrar o modificar texto puro. Es la opción preferida por velocidad y seguridad.

innerText:
Lee o establece el texto plano tal como lo ve el usuario en la pantalla.
Cuando necesitas obtener únicamente el texto que es visualmente perceptible.
